# Lumiere

Android application for rapid intake into the private Chateau Lore Heroes Feast application. Lumiere will not work without privately provisioned credentials.

This public repository holds the download page and published APKs. Application source remains in the Heroes Feast repository.

- [Download the latest APK](https://github.com/erickolb/Lumiere/releases/latest/download/Lumiere.apk)
- [Installation page](https://erickolb.github.io/Lumiere/)
- Android application ID: `net.chateaulore.lumiere`
- Requires Android 8.0 or newer.

Obtainium source URL: `https://github.com/erickolb/Lumiere`.

Releases use a stable asset name, `Lumiere.apk`, with a SHA-256 checksum in `Lumiere.apk.sha256`. Each release increases Android's versionCode and uses the same permanent Lumiere signing key. Signing keys and connection credentials are never included in this repository.
