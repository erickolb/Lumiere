Lumiere

Lumiere is an Android application for rapid intake into the private Chateau Lore Heroes Feast application.

It will not work without privately provisioned credentials. Access is limited to our family. Installing the APK does not provide access to Heroes Feast.

Install APK Add with Obtainium

Requires Android 8.0 or newer.

Installation

Open this page on your Android device. Tap Install APK, then open Lumiere.apk from your downloads. If Android asks, allow your browser to install unknown apps and complete the installation.

If you already use Obtainium, tap Add with Obtainium to install Lumiere and track updates. You can also add the repository URL manually.

After installation, open Connection in Lumiere and enter the service URL, device ID, and token supplied privately to you.
